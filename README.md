## `> featured_projects`

### [Nexum](https://github.com/itsjazzkun/Nexum)
> Backend infrastructure for systems that don't get a second chance at data integrity.

`Node.js` `Express` `MongoDB` `JWT` `RBAC` `Mongoose`

- JWT access/refresh token authentication with secure cookie handling
- Role-Based Access Control (RBAC) with granular permission matrices
- MongoDB aggregation pipelines for complex reporting queries
- Centralized error handling middleware with structured error responses
- Input validation and sanitization layers

---

### [Glyph](https://github.com/itsjazzkun/Glyph)
> Event-driven serverless pipeline that auto-parses resume PDFs using OCR and NLP.

`AWS Lambda` `S3` `Textract` `Comprehend` `DynamoDB` `API Gateway` `Python`

- S3 upload triggers Lambda for real-time resume processing
- Amazon Textract OCR extracts text from PDF documents
- Amazon Comprehend NLP identifies candidate names and skills
- DynamoDB stores structured candidate profiles as JSON
- Static S3-hosted dashboard fetches data via API Gateway
